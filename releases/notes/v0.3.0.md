Improves responsiveness and keeps lyric pages aligned with the next vocal phrase.

### Changes
- Move player queries and lyric fetching to background workers.
- Keep the fourth phrase visible until the fifth phrase actually starts.
- Advance typing by 100 ms without advancing page changes.
- Separate vocal gaps of roughly two seconds, using LRC markers or estimates.
- Use continuous weighted character progression and avoid stretching short phrases across long instrumental gaps.
- Add lyric caching and ignore results from tracks that are no longer playing.
- Restore the terminal on exit and avoid unnecessary redraws.

### Run
Requires Python 3, playerctl and syncedlyrics. Download `lyrics.py` and run `python lyrics.py`.

### Historical limitations
LRC timestamps can still be inaccurate. Unmarked pauses and character timing are estimates; no audio-based voice detection is performed.
