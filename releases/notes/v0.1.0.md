The first working version of Spotify Live Lyrics for Linux.

### Features
- Spotify metadata and playback position through playerctl.
- Synchronized LRC lyrics fetched with syncedlyrics.
- Character-by-character typewriter animation with a target of 180 FPS.
- Configurable synchronization offset and typing duration.

### Run
Requires Python 3, playerctl and syncedlyrics. Download `lyrics.py`, play a song in Spotify and run `python lyrics.py`.

### Historical limitations
Displays one line at a time. External commands run in the visual loop, and character timing is estimated from line timestamps. Later releases improve responsiveness and page layout.
