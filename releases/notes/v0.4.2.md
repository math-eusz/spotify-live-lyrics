Adds a dedicated repair path for installations that were still running the old bridge code.

### Changes
- Provide a distinctly named repair download to avoid reusing the original installer.
- Back up and replace the installed Python files.
- Verify installed file contents and import the updated bridge in a fresh Python process.
- Launch the corrected entry point directly after repair.
- Preserve the existing bridge configuration.

### Repair an existing bridge installation
Close slyrics, download `corrigir_slyrics_fallback_v3.py`, then run `python corrigir_slyrics_fallback_v3.py`. It opens the corrected player automatically. For a first installation, use the attached `install_spicy_bridge.py` instead.

### Compatibility
Requires an existing bridge installation for the repair command. Automatic fallback still requires syncedlyrics. Rendering behavior is the same as v0.4.1.

### Validation at delivery
Ten automated tests passed, including replacement of an old installation, backups and configuration preservation.
