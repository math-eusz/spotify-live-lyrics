A standalone terminal player with optional Spicy Lyrics integration, dynamic lyric pages and a configurable visualizer.

### New in 0.6.0
- Native mode by default: playerctl plus native lyric fetching, with no Spicetify requirement.
- Selectable `native`, `auto` and `spicy` sources; automatic fallback when timed bridge lyrics are missing.
- Direct LRCLIB support, optional syncedlyrics compatibility, bounded persistent caching and track-safe lookups.
- Dynamic pages based on phrase cadence and lyric pauses, with a default six-line cap and configurable maximum.
- Optional CAVA audio spectrum, bars/wave/dots styles, pause handling and only-gap visibility.
- Clearly labeled decorative animation when audio capture is unavailable; no invented instrument detection.
- Source indicator hidden by default and independently configurable.
- Real `sylrics` executable, compatibility `slyrics` name, command help and shell completion.
- Themes, live configuration by file or CLI, interactive shortcuts, demo mode and diagnostics.
- Existing weighted typewriter effect, 100 ms anticipation and stable text positioning preserved.
- Migration and backups for older installations; historical installers remain on their original tags.

### Install
Download **sylrics-0.6.0.tar.gz**, extract it, then run `sh install.sh` from the extracted directory. Open a new terminal and run `sylrics`, or run `~/.local/bin/sylrics` directly. Python 3.10+ and playerctl are required for native mode. CAVA and syncedlyrics are optional. This installer does not run Spicetify.

See [the Portuguese quick start](https://github.com/math-eusz/spotify-live-lyrics/blob/v0.6.0/QUICKSTART.pt-BR.md) for commands and examples.

### AUR preparation
**sylrics-0.6.0-aur.tar.gz** contains the PKGBUILD, .SRCINFO and a checksum matched to the source archive. The package has not been submitted to AUR: the repository is still private and AUR maintainer access has not been configured. `yay -S sylrics` is not yet an available public installation route. Recipe staging is verified; a full Arch makepkg build still requires an Arch environment.

### Limits
Dynamic grouping uses lyric timestamps, not musical mood or instrument recognition. CAVA observes the default system audio output, which can include other applications. Without CAVA, animation is decorative and labeled accordingly. Live audio and Spotify behavior need validation on the user's computer.

### Validation and backup
Automated checks cover native startup in a pseudo-terminal, source selection, fallback, seeks/pauses, lyric caching, dynamic page boundaries, configuration migration, CAVA process transport, UI layout, installation, packaging and release integrity. The previous version is preserved in `backup/before-v0.6.0` and the unchanged v0.5.0 release.
