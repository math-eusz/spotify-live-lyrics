A configurable terminal interface inspired by a minimal music player, while preserving automatic fallback and continuous typing.

### New interface
- Centered lyrics with stable positioning while characters appear.
- Thin rounded border and a warm neutral palette.
- Track title, artist and playing/paused status.
- Elapsed time, real track duration and a progress bar.
- Automatic wrapping and adaptation to terminal resizing.
- Incremental redraws and cached unchanged frames.

### Customize live
Edit `~/.config/spotify-live-lyrics/ui.ini` (or `$XDG_CONFIG_HOME/spotify-live-lyrics/ui.ini`). Save to apply changes without restarting.

Customize horizontal/vertical alignment, side padding, lyric width, line spacing, cursor, borders, progress display, footer and colors. Invalid edits keep the last valid appearance. The default background follows the terminal; font size and blur remain terminal settings.

### Install or upgrade
Close slyrics. Download `install_slyrics_interface_v4.py` and run `python install_slyrics_interface_v4.py`. It backs up the current code, preserves existing appearance settings and updates the Spicetify bridge so it sends track duration. Spotify may restart. Then run `slyrics` or `python ~/.local/share/spotify-live-lyrics/lyrics.py`.

### Preserved behavior
Four-line pages, 100 ms typing anticipation, vocal-gap separation and automatic syncedlyrics fallback remain available. Character timing is estimated; the progress bar is display-only.

### Validation at delivery
Seventeen automated tests passed, covering layout, stable centering, live settings, wrapping, bridge transport, fallback and installer contents. Appearance and live playback depend on the user's terminal and Spotify setup.
