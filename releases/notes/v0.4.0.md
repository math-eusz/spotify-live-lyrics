Introduces a local bridge between Spicy Lyrics in Spotify and the Python terminal player.

### Changes
- Read the current track's cached Spicy Lyrics data through a companion Spicetify extension.
- Send playback state and lyrics to an authenticated loopback listener.
- Support line and syllable timing data, with character interpolation inside syllables.
- Preserve four-line pages and vocal-gap separation.
- Add a standalone installer that backs up files and applies Spicetify.
- Retain the original source through `--legacy`.

### Install
Requires Python 3, Spicetify and Spicy Lyrics already installed. Download `install_spicy_bridge.py` and run `python install_spicy_bridge.py`. Spotify may restart. Open the song's lyrics in Spicy Lyrics, then run `slyrics` using your existing alias, or `python ~/.local/share/spotify-live-lyrics/lyrics.py`.

### Known issue in this historical version
The bridge does not automatically fall back when Spicy Lyrics has only unsynchronized text. Use `--legacy` or upgrade to v0.4.1 or later. Syllable-based typing can feel less continuous than the older renderer.

### Validation at delivery
Seven automated tests passed. Live Spotify compatibility still required testing on the user's installation.
