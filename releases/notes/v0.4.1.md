Fixes tracks that stopped displaying lyrics after the Spicy Lyrics integration.

### Fixes
- Automatically query syncedlyrics when Spicy Lyrics has static, empty, unsupported or missing timing data.
- Run fallback lookups in the background and cache successful results per track.
- Retry unsuccessful searches after 60 seconds.
- Prevent delayed results from replacing another song's lyrics.
- Prefer Spicy Lyrics again when usable timed data arrives.
- Restore the previous continuous weighted typewriter effect for both sources.

### Install
Download the installer attached to **this release** and run `python install_spicy_bridge.py`. Close any running slyrics process first. The installer backs up files and may restart Spotify. The `syncedlyrics` command is required for the fallback; `--legacy` is no longer needed to enable it.

### Timing behavior
Spicy Lyrics supplies phrase start/end times. Individual character timing is estimated continuously across the phrase rather than following every syllable boundary.
