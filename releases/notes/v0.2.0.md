Keeps completed lyrics visible instead of replacing every line immediately.

### Changes
- Display up to four lyric lines in the same block.
- Keep previous lines fully visible while the active line is typed.
- Start a new block when moving beyond the fourth line.

### Run
Requires Python 3, playerctl and syncedlyrics. Download `lyrics.py` and run `python lyrics.py` with Spotify playing.

### Historical limitations
Retains the original polling and estimated typing model. Dedicated pause handling and background polling arrive in v0.3.0.
